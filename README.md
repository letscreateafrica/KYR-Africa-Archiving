# KnowYourRights Africa — Archive

The public [KnowYourRights Africa Site](https://african-diaspora-brief.letscreateafrica.chatgpt.site/) publishes dated visual newsletters, full briefs, verified policy alerts and two-day digests. Its [historical U.S. Immigrant Brief tracker records](https://african-diaspora-brief.letscreateafrica.chatgpt.site/tracker/) are retrospective generated text, not freshly verified news.

It is explicitly an early partial review, prepared before the November 20–21 window ended. The [November 19 full brief](https://african-diaspora-brief.letscreateafrica.chatgpt.site/briefs/2026-11-19) and [newsletter](https://african-diaspora-brief.letscreateafrica.chatgpt.site/newsletter/2026-11-19/) cover the preceding completed window. The [two-day digest windows](https://african-diaspora-brief.letscreateafrica.chatgpt.site/digests/) are separate from the full briefs. Both new issues use distinct original covers; editorial art is presentation, not evidence. Source links and coverage limits are beside the written stories. Earlier dated pages and correction notes remain in the Site archive.

Download the [version 37 sanitized source and static build](KYR-Africa-Archiving-source-v37.zip) and the [November 19–21 original artwork](KYR-Africa-Archiving-source-art-2026-11-19-21.zip). Earlier source and artwork archives remain in this repository. To rebuild, extract the version 37 source and the relevant artwork archives into the same directory, then run `node build.mjs` and `node serve.mjs` (Node 18+). The source ZIP omits Git history, credentials and the Site identity manifest in `.openai`; it includes `dist/`, the aggregate counter function source in `backend/`, and `ARCHIVE-RECONSTRUCTION.md`.

The homepage community-reach total is the 200 launch baseline plus recorded homepage opens, not unique visitors. Its live counter uses a separate Supabase project and deployed Edge Function; no credentials are included here. Follow `EDITORIAL-WORKFLOW.md` before publishing changes. The Site provides general information, not individual legal advice.
