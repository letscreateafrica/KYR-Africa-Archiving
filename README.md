# KnowYourRights Africa — Archive

The current public site is [KnowYourRights Africa](https://african-diaspora-brief-october-5-2026.letscreateafrica.chatgpt.site/). The [historical U.S. Immigrant Brief tracker records](https://african-diaspora-brief-october-5-2026.letscreateafrica.chatgpt.site/tracker/) are retrospective generated text, not freshly verified news.

[Download the complete current source and static build](KYR-Africa-Archiving-source.zip). Extract the archive, then run `node build.mjs` and `node serve.mjs` (Node 18+). The `dist/` directory contains the static site. Follow `EDITORIAL-WORKFLOW.md` in the archive before publishing changes.

The site displays general information, not individual legal advice.
